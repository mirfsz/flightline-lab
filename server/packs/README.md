# Regional observation packs, format v1

`singapore-2026-11-18.json` is a small adapted public-data pack containing three adsb.lol public position observations captured on 2026-11-18. Contains information from **adsb.lol**, made available under the [Open Database License (ODbL-1.0)](https://opendatacommons.org/licenses/odbl/1-0/). This adapted pack is distributed under the same ODbL license; retain this attribution and license notice when sharing the pack or an adapted database. The linked license supplies the full terms, including attribution and share-alike obligations. Code licensing is separate from the data license.

The source endpoint namespace is `https://api.adsb.lol/v2/`. Source aircraft identifiers and callsign were removed before writing this pack. The assigned label `Anonymous passage A` conveys no identity. Only captured time, position, geometric altitude, ground speed and heading were retained. No receiver position or recording was captured. Aircraft positions are public source observations, not an inferred microphone position. The observation span is 24.007 seconds and makes no claim of comprehensive traffic coverage.

The loader in `server/archive.py` uses frozen typed models, rejects unknown fields and validates dates, monotonically increasing timestamps, bounded geographic extents, cell width and capture span. Each JSON pack is at most 256 KiB with 2–100 observations spanning at most 90 seconds. At most eight packs may be loaded. Version 1 supports small non-wrapping regions tiled in 0.1-degree cells; all cells must be at least 10 km across at the pack latitude, with at most sixteen cells per pack. New latitude bands may need a future format version to retain that minimum width.

Required top-level fields are `format_version=1`, a versioned `pack_id`, `region_id`, `region_label`, explicit `region_aliases`, `date_utc`, minimum `grid_resolution_km`, geographic `bounds`, `provenance`, an anonymous `passage_label`, and `observations`. Each observation contains `captured_ms`, `latitude`, `longitude`, `alt_geom_ft`, `gs_knots`, and `track_deg`. Provenance contains source name and anonymous endpoint namespace, capture date, license identifier and URL, attribution, and processing description. Do not add identity fields or identity-bearing source URLs. Unknown fields fail validation rather than leaking into responses.

Packs load into immutable tuples and frozen objects; requests do not mutate or download them. To publish a corrected observation span, create a new versioned pack artifact. `/api/archive/coverage` exposes a SHA-256 hash of the canonical validated content for audit comparison. This hash identifies content; it is not a signature or independent verification of source truth. Only coarse receiver cells and a rounded anonymous aircraft path appear in analysis output. Audio supplied by the public demo endpoint is generated synthetically from interpolation between these observations.
